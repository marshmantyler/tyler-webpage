# Tyler's Personal Homepage

A retro-inspired, 2000s-style personal homepage and blog built with pure HTML, CSS, and vanilla JavaScript. 

## Features
Retro UI: Classic Windows 95/98 aesthetic with web-safe color filters and custom scrollbars.
BGM Player: Custom floating audio player with a curated playlist.
Live Scrobbling: Integration with the Last.fm API to show the currently playing or last played track.
Static Architecture: Lightweight and fast, requiring no backend or databases.
Webrings: Classic internet webring support.

## Tech Stack
* HTML5
* CSS3
* Vanilla JavaScript
* Hosted on [Cloudflare Pages](https://pages.cloudflare.com/)
